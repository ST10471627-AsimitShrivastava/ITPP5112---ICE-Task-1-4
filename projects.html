XHAW5112 · Work Integrated Learning · Team project

Empowering the Nation

For our Work Integrated Learning module, my team built a website and a matching mobile app for a skills-training organisation that offers six-month and six-week courses such as sewing, cooking, landscaping and life skills. Visitors can browse every course, contact the organisation and use a fee calculator that applies a discount of 5%, 10% or 15% depending on how many courses they choose. It was my most collaborative project so far and taught me how to split work, share code and agree on one design.

HTML, CSS & JavaScript React Native TypeScript Teamwork

MAST5112 · Mobile app development

Christoffel's Fine Dining App

A cross-platform mobile app that lets a private chef manage and present their menu. Guests move from an elegant welcome screen to a menu that can be filtered by course, and the chef can add new dishes with a name, description, course, price and optional image through a validated form. Bottom-tab navigation keeps the app simple on any phone, and every external source is credited in the code.

PROG6112 · Java programming

Car Dealership System

A Java console application that captures a sales agent's details, works out their commission from the number of vehicles sold and prints a clear earnings report. I structured it with object-oriented principles: an Employee base class, a SalesAgent subclass and a vehicle dealer interface, so new roles can be added later without rewriting existing code.
